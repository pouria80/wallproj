# Synthetic fixtures

Files in this directory are **synthetic** modelling inputs created by this lab.
They are NOT copies of Trust Wallet source code and must never be cited as
evidence about the historical build. See docs/reproduction-methodology.md for
the separation policy between real-evidence, modelling and security-fix runs.

Contents:
- `weak_seed_corpus.json` — deterministic list of uint32 seeds used by E2/E3
  modelling experiments so those runs can be replayed exactly.
