# WalletLab — production web tool (built on the research core)

این پوشه نسخه **قابل‌اجرای واقعی** ابزار است: یک وب‌اپ گرافیکی که نشان می‌دهد
چند کیف پول ساخته شده، کدام‌ها موجودی دارند و چگونه با موتور بازیابی
بیت‌دقیق بازسازی می‌شوند.

## ساختار پوشه‌ها

| پوشه | نقش |
|---|---|
| `simulation/` | سندباکس محلی: corpus_v1.json (۱۰۰۰ کیف پول مصنوعی + موجودات شبیه‌سازی‌شده) و اسکریپت بازتولید |
| `recovery/` | موتور بازیابی دقیق (`exact_mt19937.py`) روی MT19937 راستی‌آزمایی‌شده با اوراکل g++ |
| `api/` | بک‌اند FastAPI محلی (فقط 127.0.0.1) + سرو کردن فرانت‌اند ساخته‌شده |
| `web/` | فرانت‌اند React/Vite (داشبورد، لیست ولت‌ها، صفحه بازیابی) |
| `scripts/` | `setup.sh` (نصب پیش‌نیاز + build) و `run.sh` (اجرا) |
| `tests/` | تست‌های یکپارچگی corpus و API |
| `requirements.txt` | پیش‌نیازهای پایتون این ابزار |

## اجرا (۲ فرمان)

```bash
cd trust-wallet-rng-research-lab/walletlab
bash scripts/setup.sh      # نصب fastapi/uvicorn/mnemonic + build داشبورد
bash scripts/run.sh        # http://127.0.0.1:8757
```

مرورگر را روی `http://127.0.0.1:8757` باز کنید:
- **داشبورد**: تعداد کل ولت‌ها، ولت‌های دارای موجودی / خالی، مجموع موجودی
- **ولت‌ها**: جدول با فیلتر «فقط دارای موجودی»، موجودی ETH شبیه‌سازی‌شده
- **بازیابی**: آدرس یا مونی모نيک بدهید → seed دقیق، entropy، مونیمو و موجودی
- **توضیح فنی**: زنجیره اثبات‌شده seed→MT19937→BIP-39 و محدودیت‌های صادقانه

## مرزهای ایمنی (طراحی‌شده، نه تصادفی)

1. **بدون شبکه**: هیچ درخواستی به زنجیره‌های واقعی ارسال نمی‌شود؛ تمام
   موجودی‌ها از دفتر شبیه‌سازی `simulation/corpus_v1.json` می‌آید.
2. **سقف پویش**: هر پنجره بازیابی حداکثر ۱٬۰۰۰٬۰۰۰ سید — جاروب فضای کلید
   عملاً غیرممکن است.
3. **برچسب‌گذاری صداقت**: آدرس‌ها placeholder شیمیایی (SHA-256) هستند نه
   آدرس واقعی secp256k1/EIP-55؛ نتایج همیشه `confidence=model-verified`
   و لیست `limitations` دارند.
4. **Loopback-only**: سرور از bind روی غیر-لوپ‌بک خودداری می‌کند.

## پیش‌نیازها

- Python ≥ 3.10, Node.js ≥ 18 (فقط برای build داشبورد)
- پکیج‌ها: `fastapi uvicorn mnemonic` (نگاه: `requirements.txt`)
- هسته تحقیقاتی (`src/rng_research`) باید در پوشه والد موجود باشد — این
  ابزار آن را import می‌کند، کپی نمی‌کند.
